**Audio signal classification and automatic speech recognition**

This project considers a dataset of mixed, or interfering, voices, where each data sample consists of 2 voices. The considered dataset is available at
[https://zenodo.org/search?q=minilibrimix&f=access_status%3Aopen&f=resource_type%3Adataset&l=list&p=1&s=10&sort=bestmatch
](https://zenodo.org/search?q=minilibrimix&f=access_status%3Aopen&f=resource_type%3Adataset&l=list&p=1&s=10&sort=bestmatch)
For the considered scenario, the project aims at:
1) Voice classification using semantic segmentation (pixel level), 
2) Voice separation, and 
3) Using simulated microphone-arrays, we aim at localizing the audio signals' sources.
